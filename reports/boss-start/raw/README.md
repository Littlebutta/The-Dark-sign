# Raw files for the scripted-pose work (2026-11-24), build 1.0.610 (darksign_build.txt)

All decompressed. Each folder's _index.txt lists binder ID, size, path written, original binder name.
- c7112-behbnd/: every file in Mods\ER\chr\c7112.behbnd.dcx (Export\Behaviors\c9997.hkx, Behaviors\c7112.hkx,
  Characters\c7112.hkx, Export\c7112.hkx). That binder has no .compendium.
- c7112-anibnd/tae/c7112.tae: the TAE from c7112.anibnd.dcx.
- c7112_div00/, c7112_div01/: a000_003012, 003014 (div00), a000_020003, 030001, 030002, 030003 (div01) and both
  .compendium files.
- c3061-behbnd-vanilla/: every file of vanilla ER c3061.behbnd.dcx (DarkSignPorter extract ER).
- c3061-anibnd-vanilla/: vanilla c3061.anibnd.dcx holds only hkx/skeleton.hkx, no TAE. c3061 uses c3060's TAE, so
  c3060-anibnd-vanilla/tae/c3060.tae (and its skeleton) is included.
- c7006-behbnd/: every file of Mods\ER\chr\c7006.behbnd.dcx (the ported High Wall hollow, DS3 c1100).
- hks/: loose scripts, c7112.hks and c7006.hks from Mods\ER\action\script, plus c3061-vanilla.hks and c0000-vanilla.hks
  (extract ER /action/script/...). c7112.hks and c3061 are compiled HKS bytecode; c0000 is the plain text one.
